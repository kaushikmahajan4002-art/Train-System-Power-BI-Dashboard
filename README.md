Train System Analysis – Power BI Dashboard

Project Overview
This project focuses on analysing the Indian Railway Train System using Microsoft Power BI. It provides insights into train operations, railway stations, train distances, and arrival and departure schedules through interactive dashboards.

Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization

Dashboard Pages

1. Overview Dashboard
- Total Trains
- Total Stations
- Total Distance
- Total Stops
- Train distribution by railway zone
- Train category and type analysis

2. Distance Analysis
- Train-wise distance analysis
- Top 10 long-distance trains
- Average distance by train type
- Source and destination route analysis
- Interactive Train Type and Zone filters

3. Arrival and Departure Analysis
- Station-wise stop analysis
- Railway zone analysis
- State-wise station distribution
- Arrival and departure records
- Stop sequence analysis

Key Features
- Interactive dashboards
- KPI cards
- Multiple data visualizations
- Slicers and filters
- Railway zone and state analysis
